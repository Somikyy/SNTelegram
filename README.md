# SNTelegram

**Модерация сервера прямо из Telegram.** Ответь в чате на сообщение игрока, напиши `/мут 10м` — и он
замолчал. Ник вводить не нужно, на сервер заходить не нужно, консоль открывать не нужно.

Мост чата игра ↔ Telegram здесь есть, но он не продукт, а основание. Мостов уже четыре, и делать
пятый было бы бессмысленно — а вот наказать игрока ответом на его сообщение не умеет ни один.

Бесплатно, открытый код, GPL-3.0, ноль зависимостей. Paper 1.21+ и 26.x.

---

## Зачем

Discord заблокирован в РФ с октября 2024, вместе с ним стал бесполезен DiscordSRV и весь класс
инструментов вокруг него. Комьюнити ушло в Telegram, а инструментов для Telegram почти нет: тема
[«Плагин для чата с телеграмом»](https://spigotmc.ru) от 16 июля 2025 на spigotmc.ru до сих пор без
готового ответа, а идейный предок `minecraft-telegram-bridge` заархивирован 21 июля 2024.

---

## Что это умеет

**Модерация ответом на сообщение** — то, чего нет ни у кого:

```
Игрок Steve написал в чат, сообщение прилетело в Telegram.
Ты отвечаешь на него:  /мут 10м мат в чате
```

```
🔇 Steve не сможет писать в чат 10 минут. Причина: мат в чате
```

| Команда | По-русски | Что делает |
|---|---|---|
| `/mute 10m причина` | `/мут 10м причина` | запрет писать в чат |
| `/unmute` | `/размут` | снять запрет |
| `/kick причина` | `/кик причина` | отключить от сервера |
| `/ban 7d причина` | `/бан 7д причина` | забанить |
| `/unban Ник` | `/разбан Ник` | снять бан |
| `/info` | `/инфо` | карточка игрока |
| `/list` | `/онлайн` | кто на сервере |
| `/status` | `/статус` | TPS, память, очередь |
| `/say текст` | `/сказать текст` | объявление в игровой чат |

Сроки: `10м`, `2ч`, `7д`, `навсегда`. Латиница (`10m`, `2h`, `7d`) тоже работает. Без ответа на
сообщение ник пишется первым: `/бан Ник 7д причина`.

**Мост чата** — двусторонний, с раскладкой по темам форума Telegram: чат, админка и логи в разные
темы одной группы. События: вход, выход, смерть, достижение, старт и остановка сервера.

**Импорт из другого плагина** — `/sntelegram import flectonepulse` и то же для
`mctgbridge` и `discordsrv`. Токен, chat-id и раскладку каналов не придётся искать заново.

## Установка за пять минут

1. Положи jar в `plugins/`, запусти сервер.
2. Напиши [@BotFather](https://t.me/BotFather) команду `/newbot`, получи токен.
3. Создай группу, добавь бота **администратором**. Без прав администратора он не увидит сообщения.
4. Узнай id группы: добавь в неё `@getmyid_bot`. У группы id отрицательный.
5. Впиши токен и id в `plugins/SNTelegram/config.yml`, выполни `/sntelegram reload`.

Хочешь разделить чат, админку и логи — включи в группе «Темы», создай их и впиши номера в раздел
`topics`. Номер виден в ссылке на тему: `t.me/c/1234567890/47` → `thread-id: 47`.

> **Про тему General.** У неё нет номера — пиши `thread-id: 0`. Значение `1`, которое советуют в
> интернете, верно для MTProto и **неверно** для Bot API: там оно отклоняется ошибкой 400.

## Чем отличается от других

Честно, включая то, где выигрывают конкуренты.

| | SNTelegram | tgbridge | FlectonePulse | SyncShield |
|---|---|---|---|---|
| Модерация реплаем | **да** | нет | нет | нет |
| Мут / кик / бан из Telegram | **доменные команды** | нет | нет | сырой `/rcon` |
| Карточка игрока | **да** | нет | нет | нет |
| Темы форума | да | да | да (только исходящие) | да |
| Мост чата | да | **зрелее** | да | да |
| Загрузок | новый | 13 000 | 27 000 | 54 |
| Runtime-зависимости | **ноль** | Kotlin-рантайм | есть | не заявлено |
| Лицензия | GPL-3.0 | MIT | GPL-3.0 | файла LICENSE в репозитории нет |
| Русский из коробки | да | частично | да | да |

**tgbridge зрелее как мост** и у него больше пользователей — если тебе нужен только мост, он
хороший выбор. SNTelegram имеет смысл, если модерируешь с телефона.

**Автор FlectonePulse принципиально не будет делать модерацию** — в его документации дословно:
«Commands can ONLY be informational; they do not and will not execute anything on the server».

## Чего здесь нет намеренно

**Команд `/rcon` и `/console`.** Их нет и не будет. Возможность выполнить из чата любую команду
означает, что уведённый Telegram-аккаунт админа равен полному доступу к серверу. Набор глаголов
закрыт, и самотест это проверяет:

```
  ok   команды /rcon не существует
  ok     и /console тоже
```

**Показа IP игроков** без явного включения — группа Telegram не всегда состоит только из
администрации.

**Разбора текста из Telegram как MiniMessage.** Иначе любой участник группы мог бы выдать всем
игрокам кликабельную строку, запускающую команду от их имени. Текст вставляется готовым
компонентом и не является исходником ни в один момент.

## Самотест

Полная проверка без сети и без сервера — одна команда:

```bash
bash tools/offline/verify.sh
```

90 утверждений, около 15 секунд. Внутри — настоящий сервер Bot API на `com.sun.net.httpserver`, к
которому мост подключается тем же путём, каким реальный админ подключается к своему серверу Bot
API. Тестируется код, который отгружается, вплоть до JSON на сокете.

## Что внутри

Jar — 104 КБ, 5 200 строк, ни одной сторонней библиотеки. Его можно прочитать глазами за вечер, и
это не случайность: в RU-сегменте после разбора бэкдора в мае 2026 закрытый jar от неизвестного
автора справедливо читается как угроза.

```
core/     Bot API, JSON, YAML, разбор команд, маршрутизация, хранилище.
          Ноль импортов org.bukkit — поэтому вся логика тестируется без сервера.
bukkit/   Слушатели, наказания, отрисовка, команда.
```

Клиент Bot API написан на `java.net.http` — он появился в Java 11, и тащить ради восьми методов
двухмегабайтную библиотеку незачем. JSON-читалка своя по той же причине: чужой JSON в чужом
classpath — самый частый способ сломать сервер, который плагин должен был улучшить.

## Требования

- Paper 1.21+ или 26.x (Spigot не поддерживается: нужен `AsyncChatEvent`)
- Java 17+
- Исходящий доступ к `api.telegram.org` — или прокси, или свой сервер Bot API (всё есть в конфиге)

Folia: код написан под неё — планировщики `GlobalRegionScheduler` и `AsyncScheduler` входят в
обычный `paper-api`, поэтому один и тот же вызов работает на обеих платформах. Но на живой Folia
плагин пока не проверялся, поэтому `folia-supported: false`. Ставить флаг без проверки —
ровно то, из-за чего админы перестают ему верить.
