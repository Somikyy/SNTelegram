**Ответь в Telegram на сообщение игрока и напиши `/мут 10м` — он замолчал.** Ник вводить не нужно, заходить на сервер не нужно, консоль открывать не нужно.

Первый релиз. Мост чата игра ↔ Telegram здесь тоже есть, но он не продукт, а фундамент: мостов под Telegram уже четыре, а вот наказать игрока ответом на его сообщение не умеет ни один из них.

---

### Что умеет

**Модерация ответом на сообщение.** Мут, размут, кик, бан, разбан и карточка игрока — прямо из переписки. Русские команды работают наравне с английскими: `/мут 10м флуд`, `/бан 7д гриферство`. Сроки — `10м`, `2ч`, `7д`, `навсегда`.

**Мост чата** с раскладкой по темам форума Telegram: общий чат, админка и логи в разные темы одной группы. События входа, выхода, смерти, достижений, запуска и остановки сервера.

**То же самое из консоли сервера** — `/sntelegram mute Steve 10m флуд`. Работает даже при неработающем мосте: если истёк токен или пропала связь, снять мут или бан всё равно можно.

**Импорт настроек** из FlectonePulse, minecraft-telegram-bridge и DiscordSRV одной командой.

---

### Требования

- **Paper 1.21+** или форк (Purpur, Pufferfish). Spigot не подойдёт: нужен `AsyncChatEvent`.
- **Java 17+**
- Исходящий доступ к `api.telegram.org`. Прокси и свой сервер Bot API настраиваются в конфиге.

---

### Установка

1. Положи jar в `plugins/`, запусти сервер.
2. Получи токен у [@BotFather](https://t.me/BotFather) командой `/newbot`.
3. Создай группу, добавь бота **администратором**.
4. Узнай id группы через [@getmyid_bot](https://t.me/getmyid_bot) — он отрицательный.
5. Впиши токен и id в `plugins/SNTelegram/config.yml`, выполни `/sntelegram reload`.

Для тем форума впиши их номера в раздел `topics`. Номер виден в ссылке на тему: `t.me/c/1234567890/47` → `thread-id: 47`. **У темы General номера нет — пиши `thread-id: 0`.** Значение `1`, которое советуют почти все туториалы, Telegram отклоняет ошибкой 400; плагин это распознаёт и подсказывает.

---

### Что проверено, а что нет

Честно, потому что это первый релиз и доверять ему пока не за что.

**Проверено на живом Paper 1.21:** мут не выкидывает игрока с сервера, бан отключает немедленно и корректно пишется в `banned-players.json`, временный бан истекает сам, кик, модерация из консоли, определение тем форума.

**Проверено автоматически:** 127 утверждений без сети и без сервера за 18 секунд, включая работу по настоящему сокету против сервера Bot API из JDK. Заглушки офлайн-сборки сверяются с настоящим paper-api по всем 600 ссылкам на методы.

**НЕ проверено:** запуск на 26.x. Код собирается против paper-api 26.2 на каждый коммит и не использует ни одного удалённого в Adventure 5 метода, но на живом сервере 26.x не запускался. Folia — по той же причине `folia-supported: false`, хотя код под неё написан.

---

### Чего здесь нет намеренно

Команд `/rcon` и `/console`. Их нет и не будет: возможность выполнить из чата любую команду означает, что уведённый Telegram-аккаунт админа равен полному доступу к серверу.

Показа IP игроков без явного включения. Разбора текста из Telegram как MiniMessage — иначе любой участник группы мог бы выдать игрокам кликабельную команду.
